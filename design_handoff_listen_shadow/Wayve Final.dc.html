Wayve 리뉴얼 — 학생의 하룻밤 흐름 순서
최종 결정 사항
· 홈 = 오늘의 계획 — "오늘 뭘 하면 되는지" 하나의 8분 순서로 답함. 탭 5개 → 4개 (My List는 Practice 세그먼트로)
· 모드 선택 = 바텀 시트 — 홈이 뒤에 보여 부담이 낮고, "마이크를 쓰지 않아요"가 첫 번째 선택지
· Wavi 세션 — 채팅 로그 대신 얼굴 + 마지막 한마디, 차분한 파형, 건너뛰기 상시 노출, 절제된 통과 순간
· 시각 언어 통일 — WAYVE_TOKENS(그룹 배경·20px 카드·네이비/웨이브 블루·헤어라인) + Pretendard + 라인 아이콘, 이모지·진행 바·배지 없음
2차 수정 — 듣기 → 따라 말하기, 하나의 흐름 (⑩⑪ 대체)
연구 기반 결정 사항
· 듣기 먼저, 바로 이어서 따라 말하기 — 섀도잉 연구의 표준 순서. 두 모드를 분리된 탭이 아니라 하나의 6분 세션으로 연결 (⑩A→⑩B→⑪A)
· 점수 대신 내 목소리 비교 — Whisper 채점 없음 유지. 대신 내 녹음 ↔ Wavi 재생 비교로 스스로 듣고 교정 (⑪A)
· 끝나면 성과가 보임 — "표현 4개가 입에 붙었어요" 요약 + 내일 반복 유도 (⑪B)
· 배정 전에도 시작 가능 — 신규 학생용 기본 시나리오 3종 (⑪C)
· 진행 표시는 배지·바 대신 문장 세그먼트(가는 선 6칸) — 시각 언어 규칙 유지
